# Avito Notes — заметки для объявлений Авито

**Avito Notes** — браузерное расширение для `Авито`, которое позволяет добавлять заметки к объявлениям: ставить статусы ✅ / ❌ / ❓, сохранять текстовые заметки, а также автоматически фиксировать название, цену, ссылку, изображение и координаты объявления.

Расширение рассчитано на локальное использование: данные хранятся внутри браузера в JSON-подобном хранилище.

---

## Возможности

- Заметки на карточках объявлений:
  - на странице поиска;
  - в списке объявлений рядом с картой;
  - на странице конкретного объявления.
- Быстрые статусы:
  - ✅ — подходит / нравится;
  - ❌ — не подходит;
  - ❓ — требует уточнения.
- Текстовая заметка:
  - многострочный текст;
  - короткое превью до 16 символов;
  - просмотр полной заметки при наведении;
  - пустая заметка (без статуса и текста) не хранится — при снятии статуса или
    очистке текста она удаляется автоматически.
- Автосохранение данных объявления:
  - название;
  - цена;
  - ссылка на объявление (канонический адрес по id — клик в popup всегда
    открывает само объявление, а не страницу поиска, с которой заметка была
    сделана);
  - ссылка на основное изображение;
  - координаты, если их удастся извлечь со страницы.
- Панель управления по клику на иконку расширения:
  - поиск по названию и тексту заметки;
  - фильтр по эмодзи-статусу;
  - сортировка по дате добавления;
  - сортировка по цене.
- Локальное хранение данных без внешнего сервера.

---

## Как это работает

Расширение внедряется на страницы `https://www.avito.ru/*`.

При появлении карточки объявления скрипт:

1. Находит элемент объявления.
2. Добавляет поверх карточки панель заметок.
3. Позволяет выбрать статус или добавить текст.
4. Собирает метаданные объявления.
5. Сохраняет данные во внутреннее хранилище браузера.

Панель управления расширением открывает список всех сохранённых заметок и позволяет искать, фильтровать и сортировать их.

## Разработка и тесты

```bash
npm install   # ставит только dev-зависимость jsdom
npm test      # unit + интеграционные тесты popup.js (jsdom + mock chrome.*)
```

Тесты не требуют браузера: `popup.js` загружается как CommonJS-модуль (чистые функции), а интеграционная часть выполняет его в jsdom с полным моком `chrome.storage / tabs / scripting`.

`tests/content.test.js` прогоняет `content.js` в jsdom на фрагменте реальной страницы объявления (`/voronezh/garazhi_i_mashinomesta/garazh_20_m_8093949601`) и проверяет, что:
- панель появляется без сегмента `/item/` в URL (страница определяется по стабильным якорям разметки `data-marker` / `js-*`, а не по хеш-классам, которые меняются от сборки к сборке);
- панель вставляется соседом к заголовку `h1`, а не внутрь него;
- сохранение статуса/заметки пишет корректные метаданные (название, цена,
  каноническая ссылка `/item/<id>`, координаты карты);
- если Авито перестраивает React-дерево и удаляет панель, MutationObserver
  переинжектирует её, не создавая дублей;
- пустая заметка (нет статуса и текста) автоматически удаляется из хранилища.

`tests/popup.test.js` дополнительно покрывает `resolveNoteUrl`: клик по заметке
в popup открывает само объявление — по сохранённой канонической ссылке, а для
старых записей (без ссылки или со ссылкой на страницу поиска) адрес
восстанавливается по id объявления.
