# Avito Notes — заметки для объявлений Авито

**Avito Notes** — браузерное расширение для `Авито`, которое позволяет добавлять заметки к объявлениям: ставить статусы ✅ / ❌ / ❓, сохранять текстовые заметки, а также автоматически фиксировать название, цену, ссылку, изображение и координаты объявления.

Расширение рассчитано на локальное использование: данные хранятся внутри браузера в JSON-подобном хранилище.

---

## Возможности

- Заметки на карточках объявлений:
  - на странице поиска;
  - в списке объявлений рядом с картой;
  - на странице конкретного объявления.
- Быстрые статусы:
  - ✅ — подходит / нравится;
  - ❌ — не подходит;
  - ❓ — требует уточнения.
- Текстовая заметка:
  - многострочный текст;
  - короткое превью до 16 символов;
  - просмотр полной заметки при наведении.
- Автосохранение данных объявления:
  - название;
  - цена;
  - ссылка на объявление;
  - ссылка на основное изображение;
  - координаты, если их удастся извлечь со страницы.
- Панель управления по клику на иконку расширения:
  - поиск по названию и тексту заметки;
  - фильтр по эмодзи-статусу;
  - сортировка по дате добавления;
  - сортировка по цене.
- Локальное хранение данных без внешнего сервера.

---

## Как это работает

Расширение внедряется на страницы `https://www.avito.ru/*`.

При появлении карточки объявления скрипт:

1. Находит элемент объявления.
2. Добавляет поверх карточки панель заметок.
3. Позволяет выбрать статус или добавить текст.
4. Собирает метаданные объявления.
5. Сохраняет данные во внутреннее хранилище браузера.

Панель управления расширением открывает список всех сохранённых заметок и позволяет искать, фильтровать и сортировать их.
